## Rethinking Latent Reasoning for Generative Recommendation: Beyond Teacher-Generated CoT and Recurrent Hidden-State Feedback {#arxiv-2611-09006}

**作者：** Yiwen Chen, Fuwei Zhang, Zehao Chen, Deqing Wang, Hehan Li, Peizhi Xu, Hanmeng Liu, Shuanglong Li, Xin Pei, Fuzhen Zhuang, Zhao Zhang

**命中的作者机构：** Baidu

**作者单位原文：** Baidu, Beijing, China

**论文：** [arXiv](https://arxiv.org/abs/2611.09006) · [本次阅读版本 v1](https://arxiv.org/abs/2611.09006v1)

阅读范围：完整 PDF，共 20 页（含图表、公式及附录），辅以可核对的正文片段

### 原始摘要

Latent reasoning in generative recommendation faces two practical barriers: constructing teacher-generated chain-of-thought (CoT) supervision is costly, and recurrent hidden-state feedback requires a specialized execution loop. We revisit both the supervision source and the computation interface. A step-level diagnosis measures how recommendation CoT supports next-item prediction and trace coherence. In the analyzed traces, history analysis is the only step with positive mean contributions on both dimensions, while later preference and intent steps have negative mean answer contributions. Guided by this finding, we propose PHiT (Prefilled, History-Informed Thought Tokens), which learns intermediate states from semantic targets extracted directly from observed item histories. PHiT aggregates cached sparse item encodings to construct these targets and supervises the contextual states of distinct vocabulary thought tokens. All thought tokens are supplied together as ordinary input IDs during a single causal prefill, removing the need for recurrent final-state feedback. With supervised fine-tuning alone, PHiT outperforms the compared baselines across four recommendation benchmarks. Controlled ablations support the value of input-matched semantic supervision, while cost measurements show fast target construction with training time comparable to the recommendation-only thought-token baseline.

### 一句话速览

针对生成式推荐中潜在推理依赖教师 CoT 监督和循环隐状态反馈两大成本，作者先做步级诊断，发现教师轨迹中只有历史分析步骤对预测有正贡献，据此提出 PHiT：用缓存稀疏物品编码聚合出历史语义目标监督词表 thought token，全部 token 在单次因果 prefill 中执行。仅用监督微调即在四个推荐基准上超过对比基线，目标构建成本大幅降低。

### 研究动机

- 生成式推荐把下一物品预测建模为自回归序列生成：输入是用户的交互历史，输出是目标物品的语义标识符（SID，即把物品映射成的层次化 token 序列）。推理增强型方法在预测前引入中间计算来推断用户偏好与购买意图，其中潜在推理路线把这一过程内化到隐表示中，代表性工作 LASAR 用教师 CoT 表示对齐循环隐状态，并用强化学习决定推理深度。
- 这条路线留下两个实际成本：一是监督来源依赖教师——大模型必须为每个训练样本生成推理轨迹，学生才能把轨迹压缩进隐状态；二是计算接口依赖循环——Coconut 式方法把末层隐状态反馈为下一步输入嵌入，需要 vLLM 等服务引擎的标准 token 输入与 KV-cache 路径之外的定制执行循环。
- 本文要回答两个问题：推荐 CoT 轨迹中哪些部分真正有助于监督？能否既摆脱教师生成、又摆脱循环反馈，仍获得潜在推理收益？作者通过步级诊断发现历史分析是唯一在答案贡献和连贯性上均值均为正的步骤，据此提出直接从观测物品历史构造监督目标的 PHiT。

### 方法与关键设计

- 第一步是步级诊断。教师轨迹按 Step 标记切成三个功能单元：历史分析 U1、偏好构建 U2、意图推断 U3。对目标 SID y 与上下文 z，定义长度归一化的对数似然 <span class="paper-math">&#92;(&#92;ell&#95;A(y&#92;mid z)=&#92;frac&#123;1&#125;&#123;L&#125;&#92;sum&#95;&#123;j=1&#125;^&#123;L&#125;&#92;log p&#95;&#92;theta(s&#95;j&#92;mid z,s&#95;&#123;&lt;j&#125;)&#92;)</span>，答案贡献 <span class="paper-math">&#92;(&#92;Delta A&#95;i&#92;)</span> 是完整轨迹与删除 <span class="paper-math">&#92;(U&#95;i&#92;)</span> 后轨迹的目标 SID 似然之差，连贯性贡献 <span class="paper-math">&#92;(&#92;Delta C&#95;i&#92;)</span> 则衡量保留 <span class="paper-math">&#92;(U&#95;i&#92;)</span> 与否对预测下一推理单元似然的影响。在 Beauty 训练集上，只有 U1 在两个维度上均值贡献为正，U2、U3 的答案贡献均为负，说明教师轨迹中超出观测历史的推断内容反而干扰预测。
- 第二步是目标构造。对目录中每个物品，把标题、品牌、类目和描述拼成文档，用冻结的 SPLADE 稀疏编码器得到词表级词权重并离线缓存；对用户历史 <span class="paper-math">&#92;(H&#95;u&#92;)</span>，聚合各物品词权重并取 top-K 词作为历史语义摘要：<span class="paper-math">&#92;(q&#95;u(w)=&#92;sum&#95;&#123;i&#92;in H&#95;u&#125;a&#95;i(w),&#92;quad K&#95;u=&#92;mathrm&#123;TopK&#125;&#95;w&#92;,q&#95;u(w)&#92;)</span>，再表示为关键词词表上的多热向量 <span class="paper-math">&#92;(z&#95;u&#92;)</span>。由于物品表示只编码一次、跨所有用户复用，这把每样本一次的教师生成替换为 M 次物品编码加 S 次轻量求和，且目标只来自观测历史、不接触待预测的下一物品标签。
- 第三步是 thought token 学习。模型词表扩充 N 个可训练嵌入的 thought token，以 <span class="paper-math">&#92;([x&#95;u,&#92;langle&#92;mathrm&#123;start&#125;&#92;rangle,t&#95;1,&#92;ldots,t&#95;N,&#92;langle&#92;mathrm&#123;end&#125;&#92;rangle,y&#95;u]&#92;)</span> 的形式插在历史提示与目标 SID 之间。虽然 token ID 对所有样本相同，但因果自注意力使其隐状态依赖具体用户历史。训练时对 N 个 thought token 状态做均值池化，经线性头预测 <span class="paper-math">&#92;(z&#95;u&#92;)</span>，采用类平衡二元交叉熵 <span class="paper-math">&#92;(&#92;mathcal&#123;L&#125;&#95;&#123;&#92;mathrm&#123;hist&#125;&#125;&#92;)</span> 以免负类词数量压倒正类梯度；总损失为 <span class="paper-math">&#92;(&#92;mathcal&#123;L&#125;=&#92;mathbb&#123;E&#125;&#95;u[&#92;mathcal&#123;L&#125;&#95;&#123;&#92;mathrm&#123;rec&#125;&#125;(u)+&#92;lambda&#92;mathcal&#123;L&#125;&#95;&#123;&#92;mathrm&#123;hist&#125;&#125;(u)]&#92;)</span>，其中 <span class="paper-math">&#92;(&#92;mathcal&#123;L&#125;&#95;&#123;&#92;mathrm&#123;rec&#125;&#125;&#92;)</span> 是标准自回归 SID 损失，历史提示与 thought token 块上的语言建模标签被掩蔽，<span class="paper-math">&#92;(&#92;lambda=1.0&#92;)</span>。
- 与 Coconut 式循环潜在推理的关键差异在执行接口：后者需把末层隐状态反馈为下一步输入嵌入，形成服务引擎之外的定制循环；PHiT 把全部 N 个 thought token 作为普通输入 ID 一次性送入单次因果 prefill，每层隐状态 <span class="paper-math">&#92;(h&#95;&#123;u,n&#125;^&#123;(&#92;ell)&#125;=F&#95;&#92;theta^&#123;(&#92;ell)&#125;(h&#95;&#123;u,n&#125;^&#123;(&#92;ell-1)&#125;,H&#95;&#123;u,&#92;leq n&#125;^&#123;(&#92;ell-1)&#125;)&#92;)</span> 由对历史的因果注意力产生。代价只是 prefill 序列和 KV-cache 增加 N 个位置，换来零中间自回归生成和标准 token、KV-cache 接口，可直接兼容 vLLM 类服务引擎。
- 推断时稀疏编码器与关键词头全部丢弃，只保留带 thought token 的推荐模型。一个帮助理解的例子：某用户历史包含卸甲包、CND 封层套装等美甲用品，PHiT 目标会保留 shellac、polish、coat 等直接来自物品文本的词，而教师 CoT 关键词混入 core、loyal 等推断性措辞，附录案例展示了这种对照。
- 与基线的整体差异：LASAR 需教师轨迹加 RL 后训练，LatentR3 依赖 SFT 加 RL，S2GR 用码本聚类监督；PHiT 完全去掉教师生成与 RL，仅用 SFT，用与输入历史匹配的语义目标监督固定输入的 thought token。

### 实验设计与论证方式

- 实验为离线下一物品 SID 预测，覆盖 Amazon Beauty、Instruments、Sports（沿用 GREAM 预处理划分）和 Steam（沿用 LASAR 协议），采用留一法：每条用户序列的最后一次交互作测试，验证集选超参。模型通过 beam search 解码 SID 候选列表并映射回物品，报告 NDCG@k 与 HR@k（k 取 5、10、20），Beauty 消融补充 @1 截断。这是对全物品目录的生成式排序评测，而非召回阶段筛选。
- 比较对象包括 SASRec、GRU4Rec 等传统序列推荐器，LC-Rec、MiniOneRec 等非推理生成式方法，ReaRec 潜在序列推理，显式 CoT 监督（Explicit CoT_GREAM）以及完整的 SFT 加 RL 框架 LASAR；基线分数直接引自 LASAR 基准，PHiT 仅用 SFT 训练，结果为五个随机种子平均。实现基于 Qwen3-0.6B，稀疏编码器为冻结的 SPLADE v2，每用户历史取 16 个关键词，thought token 数在验证集上从 1、2、4、8 中选择，Beauty 选 8，beam 宽度为 50。
- 消融在 Beauty 上做五种子对照：以 MiniOneRec (SFT) 为无 thought token 参照，Base 加入八个 thought token；再独立叠加四种辅助目标——跨用户打乱的历史目标、对齐教师 CoT 隐表示（MSE 损失）、预测教师派生关键词、以及与输入历史匹配的 PHiT 目标，五个条件共享同一 Stage 1 初始化。效率测量比较教师 CoT 生成与 PHiT 目标构建的离线成本及 Stage 2 训练时间。论文未报告线上 A/B 实验，本次阅读范围内也未见到代码开源声明。

### 结果与证据

- 仅用监督微调，PHiT 在四个基准的全部主表指标组合上取得最高分，其中绝大多数相对最强基线的提升达到统计显著；这支持历史语义监督加标准 prefill 的整体设计有效，但基线分数引自 LASAR 论文，跨论文比较需注意协议一致性。（Table 2, Section 5.2）

  > Evaluated across Beauty, Instruments, Sports, and Steam using supervised fine-tuning (SFT) alone, PHiT achieves the best reported results on all 24 main-table metrics, with 22 statistically significant improvements over the strongest baselines.

- 在与打乱目标对照共享架构、预测头、损失函数和目标覆盖的受控比较中，与输入历史匹配的语义目标带来一致更高的排序质量，说明增益来自目标与历史的语义对应而非额外监督信号本身；该结论限于 Beauty 消融设置。（Section 5.3）

  > The controlled five-variant comparison fixes the thought-token count. PHiT outperforms shuffled-target supervision on NDCG@5 ( <span class="paper-math">&#92;(p=0.013&#92;)</span> ). These two conditions share the architecture, head, objective, and target coverage, identifying the contribution of matched semantic targets.

- 在五个评测指标上，直接从观测物品提取的目标优于教师派生的连续表示对齐和教师关键词监督，支持诊断假设：观测历史是比教师推断更有效的监督来源；但比较仅在 Beauty 的固定 thought token 配置下进行。（Section 5.3, Table 3）

  > Across all five evaluation metrics in Table 4 , PHiT achieves the highest mean score, outperforming both continuous representation alignment ( + CoT alignment ) and discrete keyword supervision extracted from teacher traces ( + CoT keywords ). Relative to + CoT alignment , PHiT improves NDCG@1 by <span class="paper-math">&#92;(5.0&#92;%&#92;)</span> and achieves higher NDCG@5 in all five matched runs ( <span class="paper-math">&#92;(p=0.018&#92;)</span> ).

- 由于物品编码只做一次并跨用户复用，PHiT 在单 GPU 上即可快速构建全部训练目标，单位目标摊销成本远低于教师轨迹生成，说明监督构建成本的大幅下降来自离线编码复用；该测量限于 Beauty 训练集与特定硬件配置。（Section 5.4, Table 4）

  > PHiT encodes each catalog item once and reuses its cached sparse weights across user histories, constructing all 131,413 training targets in 113 seconds on a single GPU (0.86 ms per target amortized). Historical supervision preserves comparable Stage 2 training time.

论文与小组的生成式推荐、语义 ID、Attention 机制和预训练方向高度契合：免教师的 thought token 监督和标准 prefill 执行接口可直接借鉴到语义 ID 推荐系统，步级诊断协议也可用于评估自有 CoT 监督质量。可借鉴点包括缓存稀疏编码构造历史目标、类平衡辅助损失与打乱目标对照设计；待验证的是该机制在更大目录、其他骨干和线上环境中的收益。

### 局限与阅读边界

- 作者承认的局限：评测仅限基于物品元数据和交互历史的离线下一物品基准，未涉及多模态内容、演化目录和更大规模部署；方法绑定在 Qwen3 骨干与层次化语义标识符上，向其他生成式骨干和标识方案的迁移有待验证；thought token 数量固定，尚未做按请求自适应调整计算量的探索。
- 从材料可合理提出的验证问题：步级诊断只在 Beauty 训练集上测量均值与中位数，且 U1 的答案贡献中位数接近零，说明该结论对个体样本并不一致，在其他数据集和教师模板上是否成立需要检验；主表基线分数引自 LASAR 论文而非作者复跑，跨论文比较存在协议差异风险；显著性阈值取 p&lt;0.1，相对宽松，且 Beauty 上相对 MiniOneRec 的增益虽比例明显，绝对量级在千分位，线上场景的实际价值需进一步确认。

## MV-IVF: Multi-Vector Retrieval via Multi-Vector Clustering {#arxiv-2611-09040}

**作者：** Kishen N Gowda, Laxman Dhulipala, Lars Gottesbüren, Rajesh Jayaram

**命中的作者机构：** Google

**作者单位原文：** Google Research , Zürich , Switzerland；Google Research , New York City , NY , USA；Google Research

**论文：** [arXiv](https://arxiv.org/abs/2611.09040) · [本次阅读版本 v1](https://arxiv.org/abs/2611.09040v1)

### 原始摘要

Multi-vector retrieval represents each query and document as a set of embeddings and scores relevance via fine-grained set-to-set interactions such as MaxSim (Chamfer similarity). This expressiveness improves retrieval quality over single-vector representations, but makes search substantially more expensive. Existing systems address this challenge primarily through proxy representations or filter-and-rerank pipelines that reduce candidate generation to single-vector search. We study the complementary direction of building a native IVF-style index directly over multi-vector data. We introduce MV-IVF, an inverted-file index for multi-vector retrieval built on MV-Lloyd, a new Lloyd-style algorithm for clustering point clouds under a Chamfer objective. Our key observation is that once point clouds are assigned to clusters, the center-update step reduces to standard single-vector clustering over the flattened embeddings in each cluster. This enables efficient construction of a hierarchical IVF tree with center point clouds at internal nodes. At query time, MV-IVF performs best-first beam search over the tree to identify promising leaf clusters, then scores the documents in those leaves. We further accelerate search using low-bit quantization, query compression, and cache-efficient batched search. We implement MV-IVF in MVSIC, an optimized C++ library and unified evaluation framework for multi-vector retrieval that includes several major approaches. Across BEIR and LoTTE text retrieval benchmarks, MV-IVF achieves strong latency--recall tradeoffs, the best batched throughput frontiers, and favorable build-time and index-size profiles. At <span class="paper-math">&#92;(90&#92;%&#92;)</span> Recall-<span class="paper-math">&#92;(10&#92;)</span>@<span class="paper-math">&#92;(10&#92;)</span>, MV-IVF achieves up to <span class="paper-math">&#92;(8.03&#92;times&#92;)</span> lower single-query latency and up to <span class="paper-math">&#92;(173.5&#92;times&#92;)</span> higher QPS than the baselines, demonstrating that native IVF-style indexing is practical and effective for scalable multi-vector retrieval.

### 一句话速览

论文研究多向量检索（如 ColBERT 的 MaxSim 打分）的索引效率问题，提出 MV-IVF：用 MV-Lloyd 聚类算法在点云数据上直接构建层次化倒排索引，配合低比特量化、查询压缩与按叶子分组的批量检索。在 BEIR 与 LoTTE 八个数据集上，MV-IVF 在召回—延迟与吞吐前沿上优于 SVH、MUVERA 等基线，证明原生 IVF 式多向量索引切实可行。

### 研究动机

- 多向量检索把每条查询和每个文档表示为一组嵌入（点云），用 MaxSim 这类集合到集合的细粒度交互打分，典型场景是 ColBERT 式 late-interaction 文本检索和 ColPali 式图像区域表示。相比单向量表示，这种表示检索质量更高，但一次查询—文档打分需要大量内积计算，全库穷举代价过高，核心挑战是在不穷举的情况下恢复 MaxSim 下的 top-k 文档。
- 现有系统大多走代理表示或过滤—重排路线：SVH（PLAID/WARP 的候选生成方式）在扁平化单向量上做 ANN 检索，MUVERA 把点云映射成固定维度编码（FDE）再做单向量 MIPS，最后只对少量候选做精确 MaxSim 重排。这些方法有效，但最终 top-k 质量取决于代理阶段能否保住 MaxSim 下的高分文档。
- 本文问一个互补问题：能否直接在多向量表示上构建可扩展索引，同时准确保留 MaxSim 下的 top-k 结果？已有少量原生方案基于哈希（DESSERT）或图（IGP），作者选择把单向量检索中最常用的 IVF 聚类范式推广到点云数据，难点在于如何聚类点云以及用什么代表来路由查询。

### 方法与关键设计

- 首先明确打分规则。给定查询点云 <span class="paper-math">&#92;(A&#92;)</span> 和文档点云 <span class="paper-math">&#92;(B&#92;)</span>，MaxSim 定义为 <span class="paper-math">&#92;(&#92;mathrm&#123;MaxSim&#125;(A,B):=&#92;sum&#95;&#123;a&#92;in A&#125;&#92;max&#95;&#123;b&#92;in B&#125;&#92;langle a,b&#92;rangle&#92;)</span>，即每个查询嵌入找文档侧最相似的嵌入再求和；聚类则用非对称 Chamfer 距离 <span class="paper-math">&#92;(&#92;mathtt&#123;Ch&#125;(A,B):=&#92;frac&#123;1&#125;&#123;|A|&#125;&#92;sum&#95;&#123;a&#92;in A&#125;&#92;min&#95;&#123;b&#92;in B&#125;&#92;|a-b&#92;|&#95;&#123;2&#125;&#92;)</span>。检索目标是返回 MaxSim 下的 top-k 文档点云。
- 核心算法 MV-Lloyd 解决 Chamfer <span class="paper-math">&#92;((k,s)&#92;)</span>-median 问题：找 <span class="paper-math">&#92;(k&#92;)</span> 个大小不超过 <span class="paper-math">&#92;(s&#92;)</span> 的中心点云，最小化所有文档点云到最近中心的 Chamfer 距离之和。算法像经典 Lloyd 迭代一样交替两步：分配步把每个点云分到 Chamfer 距离最近的中心；更新步重算每个簇的中心点云。
- 关键观察在更新步：一旦点云到簇的分配固定，求簇 <span class="paper-math">&#92;(&#92;Pi&#95;j&#92;)</span> 的最优中心等价于在扁平化多重集 <span class="paper-math">&#92;(&#92;textsf&#123;Flatten&#125;(&#92;Pi&#95;j)&#92;)</span>（把簇内所有点云的嵌入合并，每个嵌入带权重 <span class="paper-math">&#92;(w(x)=1/|P|&#92;)</span>）上解一个加权 <span class="paper-math">&#92;(s&#92;)</span>-median 问题。论文用命题证明 <span class="paper-math">&#92;(&#92;sum&#95;&#123;P&#92;in&#92;Pi&#95;j&#125;&#92;mathtt&#123;Ch&#125;(P,C)=&#92;sum&#95;&#123;x&#125;&#92; w(x)&#92;cdot&#92;min&#95;&#123;c&#92;in C&#125;d(x,c)&#92;)</span>，因此多向量的复杂性只出现在分配步，更新步可复用高度优化的单向量聚类实现。实际实现中用带余弦相似度的 <span class="paper-math">&#92;(s&#92;)</span>-means 更新，以匹配归一化嵌入的几何并利用现成 k-means 内核。
- 索引构建：MV-IVF 递归地用 MV-Lloyd 划分文档点云，分支因子为 <span class="paper-math">&#92;(b&#92;)</span>、中心点云大小为 <span class="paper-math">&#92;(s&#92;)</span>，每个子节点存自己的中心点云，直到节点点云数不超过最大叶子大小 <span class="paper-math">&#92;(&#92;ell&#95;&#123;&#92;max&#125;&#92;)</span> 即成为叶子。这样得到一棵内部节点存中心点云、叶子存文档点云的树，是标准 k-means 树的多向量类比。
- 查询时做 best-first 束搜索：从根出发，用查询点云与子节点中心点云的 MaxSim 分数扩展最高分内部节点，维护大小为 beam_size 的内部节点束和 top-nprobe 叶子列表；当束中最佳剩余节点的 MaxSim 不超过当前最差已选叶子时提前终止。作者明确说明这是启发式——中心点云只是路由代表，不是子树分数的 certified 上界，但经验上大幅省时且几乎不损质量。找到叶子后对其中文档点云做 MaxSim 打分返回 top-k。
- 批量检索按叶子分组：许多查询会探测相同叶子，独立处理会重复加载同一叶子数据浪费内存带宽。MV-IVF 在根层对整批查询做 many-to-many MaxSim 打分，之后各查询独立束搜索，最后把工作按叶子聚合——加载一次叶子数据、对分到该叶子的所有查询一起打分，再 scatter-and-gather 汇总每查询的 top-k。系统层面还叠加三种量化（随机旋转后 1 比特符号位、TurboQuant 4 比特、自适应 8 比特）和 Ward 聚合式查询压缩（把查询嵌入分块、每块用向量和代表，保持 MaxSim 尺度）。与基线的差别在于：SVH 和 MUVERA 的候选生成发生在单向量代理空间，MV-IVF 的索引对象和路由代表都保持点云形态。

## RedMall: Generative Recommendation for Large-Scale E-commerce {#arxiv-2611-08519}

**作者：** Kunyang Zhou, Xin Jia, Yi Yang, Yongjun Yang, Manjie Xu, Honglei Zhang, Yan Zhu, Kai Zuo, Xu Tang, Zheng Wang

**命中的作者机构：** Xiaohongshu

**作者单位原文：** Xiaohongshu Inc

**论文：** [arXiv](https://arxiv.org/abs/2611.08519) · [本次阅读版本 v1](https://arxiv.org/abs/2611.08519v1)

### 原始摘要

Generative recommendation has shown considerable potential in industrial recommendation systems. However, the performance of existing generative methods is limited by several challenges. 1) Semantic IDs (SIDs) are treated as one-dimensional sequences, overlooking the hierarchical dependencies among different layers. 2) Next-token prediction used is unable to explicitly optimize session-wise recommendation. 3) Although reinforcement learning has been applied to align generated recommendations with user preferences, few existing methods explicitly optimize the ranking of positive items in session-wise recommendation. To address the above issues, we propose RedMall, a generative recommender designed for large-scale e-commerce. Firstly, RedMall constructs hierarchical SIDs through residual quantization over multimodal representations. Secondly, RedMall introduces a lightweight SID encoder to explicitly model layer-wise dependencies in SIDs. Moreover, RedMall incorporates sparse mixture-of-experts, dual gated attention, and multi-target prediction to scale model size, enhance user interest representation, and optimize session-wise recommendation. We further design an exposure-aware loss that treats exposed but unclicked items as negative feedback. To better align user preferences and list-wise ranking objectives, we combine Group Relative Policy Optimization with an auxiliary LambdaRank loss, using both real user feedback and item ranking to guide optimization. Experiments on four public datasets-Amazon Beauty, Amazon Toys, Amazon Food, and MovieLens-1M---show that RedMall outperforms the evaluated baselines across all reported Recall and NDCG metrics. Online A/B tests show improvements of 2.24% in advertiser value (ADVV) and 0.59% in click-through rate (CTR) for e-commerce advertising, as well as gains of 1.08% in GMV and 0.95% in daily active buyers (DAB) for e-commerce recommendations.

### 一句话速览

小红书团队提出面向大规模电商的生成式推荐模型 RedMall：用多模态残差量化构建层次化语义 ID，配轻量 SID 编码器、稀疏 MoE 解码器、多目标预测与双门控注意力，并引入曝光感知负反馈损失和 GRPO+LambdaRank 对齐。四个公开数据集上 Recall/NDCG 全面领先基线，线上 A/B 在广告与推荐场景均取得业务指标提升。

### 研究动机

- 大规模电商平台要在亿级、持续更新的商品库中，根据用户按时间排列的交互历史预测其未来兴趣并召回候选商品。传统序列推荐模型（如 GRU4Rec、SASRec、BERT4Rec）对预定义商品目录逐个打分，随着商品空间和场景扩张，检索效率面临压力。生成式推荐提供了另一条路线：用残差量化把商品表示成离散语义 ID（SID）序列，把召回转化为条件序列生成，TIGER 确立了这一范式，OneRec 系列把它推进到工业级端到端系统。
- 但论文指出该范式仍有四个缺口：一是 SID 各层本有层次依赖（后层码由前层派生），现有方法多把它当作一维扁平序列，Tree-Transformer 虽用树感知位置编码弥补，却可能破坏原始序列位置信息；二是标准的下一物品预测（NTP）每个上下文只监督一个后续物品，与实际需要一次召回多个相关物品的会话式推荐不对齐；三是只监督点击，曝光未点击这一负反馈信号被浪费；四是强化学习对齐多优化候选级奖励，未显式优化推荐列表内候选的相对排序。
- 本文要回答的问题是：能否在工业电商场景下，通过 SID 构建、模型结构和训练目标的协同设计，同时解决层次建模、多目标监督、负反馈利用和列表级排序对齐，并在公开基准与真实线上系统中验证收益。

### 方法与关键设计

- 物品侧表示与 SID 构建：内容编码器给出文本嵌入 <span class="paper-math">&#92;(&#92;mathbf&#123;e&#125;^&#123;t&#125;&#92;)</span> 和视觉嵌入 <span class="paper-math">&#92;(&#92;mathbf&#123;e&#125;^&#123;v&#125;&#92;)</span>，经模态专属投影得到 <span class="paper-math">&#92;(&#92;mathbf&#123;h&#125;^&#123;t&#125;&#92;)</span>、<span class="paper-math">&#92;(&#92;mathbf&#123;h&#125;^&#123;v&#125;&#92;)</span>，再用学习到的门控 <span class="paper-math">&#92;(&#92;mathbf&#123;g&#125;=&#92;sigma(&#92;mathbf&#123;W&#125;&#95;g[&#92;mathbf&#123;h&#125;^&#123;t&#125;;&#92;mathbf&#123;h&#125;^&#123;v&#125;]+&#92;mathbf&#123;b&#125;&#95;g)&#92;)</span> 做逐元素融合 <span class="paper-math">&#92;(&#92;mathbf&#123;x&#125;=&#92;mathbf&#123;g&#125;&#92;odot&#92;mathbf&#123;h&#125;^&#123;t&#125;+(&#92;mathbf&#123;1&#125;-&#92;mathbf&#123;g&#125;)&#92;odot&#92;mathbf&#123;h&#125;^&#123;v&#125;&#92;)</span>，按物品自适应调节模态贡献。融合向量再经按时间序列的 next-item 预测做后训练，把行为共现与转移结构注入嵌入，同时保留新品的内容特征。
- 量化采用 RQ-VAE：在第 <span class="paper-math">&#92;(&#92;ell&#92;)</span> 层从码本 <span class="paper-math">&#92;(&#92;mathcal&#123;C&#125;&#95;&#92;ell&#92;)</span> 中选最近码字 <span class="paper-math">&#92;(&#92;mathbf&#123;q&#125;&#95;&#92;ell=&#92;arg&#92;min&#95;&#123;&#92;mathbf&#123;e&#125;&#92;in&#92;mathcal&#123;C&#125;&#95;&#92;ell&#125;&#92;|&#92;mathbf&#123;r&#125;&#95;&#92;ell-&#92;mathbf&#123;e&#125;&#92;|&#95;2^2&#92;)</span>，残差 <span class="paper-math">&#92;(&#92;mathbf&#123;r&#125;&#95;&#123;&#92;ell+1&#125;=&#92;mathbf&#123;r&#125;&#95;&#92;ell-&#92;mathbf&#123;q&#125;&#95;&#92;ell&#92;)</span> 传入下一层。三层码本大小分别为 8192、1024、128，前层编码粗语义、后层编码残差细节，选出的码字索引即 SID。训练目标 <span class="paper-math">&#92;(&#92;mathcal&#123;L&#125;&#95;&#123;&#92;mathrm&#123;SID&#125;&#125;&#92;)</span> 由重建误差与带 stop-gradient 的 commitment 项组成，用 straight-through estimator 传梯度；码本用衰减 0.995 的指数滑动平均在线更新，使用率低于 0.2 的码字从当前 mini-batch 重初始化以防码本塌缩。
- SID 编码器是即插即用模块：三层 SID 嵌入（与编码器 SID 嵌入层共享权重）经修改前馈网络 MFFN 沿层维做跨层融合，再由三个 MLP 映回各层专属表示 <span class="paper-math">&#92;(&#92;mathbf&#123;h&#125;^&#123;(i)&#125;&#92;)</span>，逐层加到编码器输入上。这样在不改动原始序列位置编码的前提下，把“后层依赖前层”的层次结构显式暴露给模型，区别于 Tree-Transformer 用树感知位置编码、可能牺牲序列位置信息的做法。
- 解码器以 TIGER 为基础并做三处增强。其一，把 FFN 子层替换为稀疏 MoE，每个 MoE 含 12 个专家、推理时只激活 2 个，整体约 0.5B 总参数、0.1B 激活参数；每个专家是带预归一化和残差连接的门控前馈网络，两支并行投影后逐元素相乘。其二，多目标预测（MTP）：每条训练序列保留最后 N 个物品作目标、前缀作共享上下文，每个目标单独前向并保留自回归 token 级损失后求和，实验中 N 取 5，对齐一次会话需召回多个物品的场景。其三，双门控注意力：引入门控调制注意力输出，并把历史物品间的因果掩码换成双向注意力——推荐条件于已完整观测的历史，历史物品互相可见不违反预测边界，能让每个历史物品同时被前后交互上下文化。
- 曝光感知损失利用曝光日志：对每个目标交互，收集窗口大小为 5 内曝光未点击物品，取其最频繁的一级 SID 作负目标。正损失 <span class="paper-math">&#92;(&#92;mathcal&#123;L&#125;&#95;&#123;&#92;mathrm&#123;pos&#125;&#125;&#92;)</span> 鼓励生成完整三层 SID，负损失 <span class="paper-math">&#92;(&#92;mathcal&#123;L&#125;&#95;&#123;&#92;mathrm&#123;neg&#125;&#125;=-&#92;sum&#92;log[1-p&#95;&#92;theta(&#92;bar&#123;s&#125;^&#123;(1)&#125;|&#92;mathcal&#123;H&#125;)]&#92;)</span> 抑制该负 SID 前缀的生成概率，二者加权平均为 <span class="paper-math">&#92;(&#92;mathcal&#123;L&#125;&#95;&#123;&#92;mathrm&#123;EA&#125;&#125;&#92;)</span>，<span class="paper-math">&#92;(&#92;alpha&#92;)</span> 控制负监督强度。
- 后训练 RL 采用 GRPO 加 LambdaRank 辅助损失。奖励模型用排序模型 SIM，从用户 SID 序列预测 pCTR 和 pCVR；同时用真实日志：未来窗口（大小 5）内被点击的 SID 序列作正样本，反馈奖励按预测 SID 与点击 SID 逐层匹配计数，取值 0 到 3。总奖励 <span class="paper-math">&#92;(R&#95;i=R&#95;&#123;&#92;mathrm&#123;feedback&#125;&#125;+&#92;alpha&#92;,&#92;mathrm&#123;pCTR&#125;+&#92;beta&#92;,&#92;mathrm&#123;pCVR&#125;&#92;)</span>，实验中 <span class="paper-math">&#92;(&#92;alpha=&#92;beta=1&#92;)</span>。LambdaRank 损失对同一请求采样的候选做配对排序，用 <span class="paper-math">&#92;(|&#92;Delta&#92;mathrm&#123;NDCG&#125;&#95;&#123;ij&#125;|&#92;)</span> 加权，使高奖励候选获得更高模型分，总目标为 <span class="paper-math">&#92;(&#92;mathcal&#123;L&#125;=&#92;mathcal&#123;L&#125;&#95;&#123;&#92;mathrm&#123;GRPO&#125;&#125;+&#92;lambda&#95;&#123;&#92;mathrm&#123;rank&#125;&#125;&#92;mathcal&#123;L&#125;&#95;&#123;&#92;mathrm&#123;LambdaRank&#125;&#125;&#92;)</span>。线上部署还解决两个工程问题：同一 SID 下多物品用 GPM/OPM 后验分数排序只保留 top-K（生产取 40），并用 KV 缓存、批处理和多线程加速推理。

### 实验设计与论证方式

- 离线实验在 Amazon Beauty、Toys、Food 和 MovieLens-1M 四个公开数据集上进行，采用 5-core 预处理并保留每用户最近 20 条交互，按 leave-one-out 划分。指标为 Recall@K 和 NDCG@K（K 取 5 和 10），传统模型在全物品集上打分，生成式模型用约束 beam search 保证生成序列映射到合法物品。基线覆盖 GRU4Rec、SASRec、BERT4Rec、HSTU、HyMiRec、TIGER 和 Tree-Transformer，基线超参按原文推荐范围搜索并按验证集择优。实现上编码器和解码器各 4 层，GRPO 组大小 32，beam 宽度公开数据集为 10、线上为 50，训练在 56 块 H800 GPU 上进行。
- 消融在工业数据集上进行，指标为 HitRate@50，训练集含约 1.5 亿用户（近一个月点击 SID 序列），评估集为 1.6 万用户、以最近一次购买为目标，按 MTP、MoE、SID 编码器、双门控注意力、曝光感知损失、RL 的顺序逐级累加。线上 A/B 部署在工业推荐系统的召回阶段：广告场景 10% 对 10% 流量、至少 7 天，候选集仅含 24 小时内发布的新品；推荐场景同样 10% 对 10% 流量、7 天。论文还报告了 intra-SID 物品排序策略的线上消融与下游透传率分析。
- 需区分任务边界：公开数据集是单目标序列推荐的 top-K 评估，工业消融是 HitRate@50 召回命中评估，线上是召回阶段对下游业务指标的影响，三者候选空间和协议不同，不能直接比较。论文未报告开源代码信息，本次也未核验复现环境。

## AttentionSwitch: Jailbreak Defense for LLMs via Joint Learning of Sparse Attention-Head Selection and Scaling {#arxiv-2611-08752}

**作者：** Doniyorkhon Obidov, Honggang Yu, Xiaolong Guo, Kaichen Yang

**命中的作者机构：** Michigan

**作者单位原文：** Michigan Technological University

**论文：** [arXiv](https://arxiv.org/abs/2611.08752) · [本次阅读版本 v1](https://arxiv.org/abs/2611.08752v1)

阅读范围：完整 PDF，共 19 页（含图表、公式及附录），辅以可核对的正文片段

### 原始摘要

Large language models have achieved remarkable performance across a wide range of tasks, yet they remain susceptible to jailbreak attacks that circumvent safety mechanisms and elicit harmful or unintended outputs. Although safety can be improved through model fine-tuning, such approaches can be computationally expensive and may degrade previously acquired capabilities through catastrophic forgetting. Recent jailbreak defenses have therefore explored targeted interventions on specific model components associated with unsafe behavior. However, existing approaches typically decouple two inherently related decisions: where to intervene and how to modify the selected components. Such sequential optimization may be suboptimal because the optimal intervention location can depend on the intervention applied there, and vice versa. In this work, we introduce AttentionSwitch, the first jailbreak defense to jointly optimize intervention sites and strengths within a frozen LLM. Specifically, AttentionSwitch learns a sparse set of attention heads together with query-conditioned multiplicative scaling factors, allowing the outputs of the selected heads to be either attenuated or amplified without altering the directions of their representations. Across popular language models and jailbreak attacks, AttentionSwitch outperforms existing defenses, with particularly strong results when training data is scarce.

### 一句话速览

提出 AttentionSwitch，在冻结 LLM 上用 Gumbel-Softmax 联合学习稀疏注意力头选择与查询条件化的输出缩放因子，以防御越狱攻击。在五个模型、九类攻击的离线基准上，其攻击拒绝率最高且良性能力几乎无损，低数据场景优势尤其明显；结论限于文本越狱防御基准，未含线上部署验证。

### 研究动机

- 大语言模型部署后仍易受越狱攻击：攻击者通过精心构造的提示绕过安全机制，诱导模型输出有害内容。防御方需要在模型权重冻结或可微调的前提下提升安全性，同时不能损害模型原有的指令遵循和通用能力。威胁模型设定为攻击者完全了解模型架构和参数（可发起白盒或黑盒攻击），但只能通过提示交互，不能修改部署的模型；防御方拥有模型及其内部激活的完全访问权。
- 传统对齐手段如 SFT 和 RLHF 需要大量数据重训练，计算开销大，且可能通过灾难性遗忘损害已有能力。近期防御转向对安全相关组件的定向干预：有的作用于选定层的隐藏表示（如 Jailbreak Antidote、AlphaSteer、DDPO），有的作用于单个注意力头（如 DeTAM、CAST、ASGuard）。
- 作者指出这些方法共同遵循“先诊断后干预”的范式：先确定干预位置，再在固定位置上优化干预方式。这种顺序优化可能次优，因为最优干预位置取决于施加的干预，反之亦然。本文要回答的问题是：能否在冻结 LLM 中联合优化干预位置和强度，用稀疏的注意力头缩放同时提升越狱鲁棒性和保留良性能力，尤其在训练数据稀缺时。

### 方法与关键设计

- AttentionSwitch 的核心是在冻结的 LLM 上学习两件事：哪些注意力头需要干预（稀疏选择），以及每个被选头在当前 token 位置应如何缩放。与 ASGuard 等先诊断后干预的范式不同，它把“在哪干预”和“如何干预”放在同一个训练目标下联合优化，理由是最优干预位置可能依赖干预强度，反之亦然。
- 缩放机制：对被选头 h 在层 ℓ、位置 t 的输出向量 <span class="paper-math">&#92;(&#92;mathbf&#123;o&#125;&#95;&#123;&#92;ell ht&#125;&#92;)</span>，乘以一个查询条件化的正标量 <span class="paper-math">&#92;(&#92;alpha&#95;&#123;&#92;ell ht&#125;&#92;)</span>，即 <span class="paper-math">&#92;(&#92;widehat&#123;&#92;mathbf&#123;o&#125;&#125;&#95;&#123;&#92;ell ht&#125;=&#92;alpha&#95;&#123;&#92;ell ht&#125;&#92;mathbf&#123;o&#125;&#95;&#123;&#92;ell ht&#125;&#92;)</span>。缩放因子由该头自身的查询表示计算：<span class="paper-math">&#92;(&#92;alpha&#95;&#123;&#92;ell ht&#125;=&#92;exp&#92;!&#92;left[&#92;lambda&#92;,g&#92;!&#92;left(&#92;frac&#123;&#92;widetilde&#123;&#92;mathbf&#123;q&#125;&#125;&#95;&#123;&#92;ell ht&#125;^&#123;&#92;top&#125;&#92;mathbf&#123;w&#125;&#95;&#123;&#92;ell h&#125;&#125;&#123;&#92;sqrt&#123;d&#95;&#123;h&#125;&#125;&#125;+b&#95;&#123;&#92;ell h&#125;&#92;right)&#92;right]&#92;)</span>，其中 <span class="paper-math">&#92;(&#92;widetilde&#123;&#92;mathbf&#123;q&#125;&#125;&#92;)</span> 是 RMS 归一化后的查询向量，<span class="paper-math">&#92;(&#92;mathbf&#123;w&#125;&#95;&#123;&#92;ell h&#125;&#92;)</span> 和 <span class="paper-math">&#92;(b&#95;&#123;&#92;ell h&#125;&#92;)</span> 是可学习参数，<span class="paper-math">&#92;(g&#92;)</span> 取 tanh，<span class="paper-math">&#92;(&#92;lambda=&#92;log 5&#92;)</span> 控制干预幅度。因为整个头输出被同一个正标量均匀缩放，表示方向和特征相对构成保持不变，只改变幅度；<span class="paper-math">&#92;(&#92;alpha=1&#92;)</span> 恢复原计算，小于 1 削弱、大于 1 放大该头贡献。这使干预是“非破坏性”的，有助于保留良性能力。
- 头选择通过 Gumbel-Softmax 松弛实现：每个头有一个可训练的 selector logit <span class="paper-math">&#92;(s&#95;j&#92;)</span>，训练时加 Gumbel 噪声 <span class="paper-math">&#92;(z&#95;j=s&#95;j+&#92;gamma&#95;j&#92;)</span> 进行随机探索；前向传播使用离散的 Top-K 掩码 <span class="paper-math">&#92;(&#92;overline&#123;&#92;mathbf&#123;m&#125;&#125;&#92;)</span>（保证每次前向恰好 K 个头被干预），反向传播用可微代理 <span class="paper-math">&#92;(&#92;widetilde&#123;&#92;mathbf&#123;m&#125;&#125;=K&#92;operatorname&#123;softmax&#125;(&#92;mathbf&#123;z&#125;/&#92;tau)&#92;)</span> 近似梯度。合并后的干预为 <span class="paper-math">&#92;(&#92;widehat&#123;&#92;mathbf&#123;o&#125;&#125;&#95;&#123;&#92;ell ht&#125;=&#92;left[1+m&#95;&#123;&#92;ell h&#125;&#92;left(&#92;alpha&#95;&#123;&#92;ell ht&#125;-1&#92;right)&#92;right]&#92;mathbf&#123;o&#125;&#95;&#123;&#92;ell ht&#125;&#92;)</span>。
- 训练分三阶段：先用全部头激活优化缩放控制器参数作为初始化；再联合优化 selector 参数（在哪干预）和缩放参数（如何缩放）；最后去掉 Gumbel 扰动，确定性地选出 logit 最大的 K 个头，丢弃 selector，仅对选中头进一步精调缩放函数。训练目标是自回归负对数似然，有害提示配对模型自身的拒绝续写、良性提示配对未防御模型的原始续写，从而在鼓励拒绝有害输入的同时保持良性输出。
- 推断时缩放只在处理输入提示（prefill）阶段施加，生成 token 位置不干预，干预通过缓存的 key/value 状态影响自回归解码。缩放控制器仅需 <span class="paper-math">&#92;(K(d&#95;h+1)&#92;)</span> 个参数，对十亿到百亿参数的模型约为万级参数量级，新增参数占比约百万分之二到四。与基线的差异：SFT/LoRA-SFT 更新模型参数且在低数据下严重损害良性能力；ASGuard 对每个选中头内不同维度用固定缩放向量（可改变方向）且不联合优化选择；DDPO 在中间层表示上做深度提示优化。

### 实验设计与论证方式

- 实验覆盖五个开源模型（DeepSeek-LLM-7B-Chat、OpenChat-3.5-1210、Llama-3.1-8B-Instruct、Vicuna-13B-v1.5、Gemma-3-27B-IT），训练预算为 30 或 120 个样本（有害与良性各半），有害训练样本均分自 Plain Harmful、Human-Crafted 和 GCG 三类攻击，其余六种攻击在测试时为零样本。有害测试集共 2,115 条未见提示，另有 500 条良性指令提示和 250 条过拒绝提示（来自 XSTest）。指标为攻击拒绝率（ARR）、良性通过率（BPR）、过拒绝率（ORR）和 MMLU，前三项由 WildGuard 作为裁判模型评估，作者用 540 条人工标注验证裁判与人类判断的一致率约 97%。比较对象包括 SFT、LoRA-SFT、ASGuard 和 DDPO。
- 消融包括头选择消融（对比全头缩放和用 ASGuard 选择器先选头再缩放的非联合变体）、缩放头比例扫描（1% 到 100%），以及自适应 GCG 和 PAIR 攻击（各 50 条测试提示）。所有实验为离线基准，论文未报告线上部署或 A/B 结果；作者在可复现性声明中说明随附代码、数据和 README，本次未核验仓库内容。

## Energy-Based Reasoners: Your Recurrent Reasoner Should Be an Energy-Based Model {#arxiv-2611-08977}

**论文：** [arXiv](https://arxiv.org/abs/2611.08977) · [本次阅读版本 v1](https://arxiv.org/abs/2611.08977v1)

### 原始摘要

Looping is a powerful inductive bias for reasoning. By repeatedly iterating a recurrent block, looped models can scale their effective depth and enable multi-step reasoning in latent space. However, existing looped models are not inherently guided by an explicit measure of progress, making it difficult to determine when to stop looping and how to improve upon the current state. To enable this, we introduce Energy-Based Reasoners (EBRs), which learn an energy function over latent reasoning states and formulate looped updates as gradient descent on this energy. The energy scores latent states, while its gradient guides refinement and provides a signal for stopping. To train EBRs effectively, we further introduce exploration-based training to discover additional modes and to better shape the energy landscape over a broader set of states. Across four algorithmic reasoning benchmarks, EBRs match or outperform prior recurrent reasoning models, achieving 99.9% accuracy on Sudoku-Extreme while using 345<span class="paper-math">&#92;(&#92;times&#92;)</span> less inference compute than the next-best model and maintaining comparable training compute. On all multi-solution benchmarks, EBRs achieve state-of-the-art coverage of distinct valid solutions while maintaining near-100% single-sample accuracy. These results suggest that energy-based models are a promising approach for strong reasoning performance.

### 一句话速览

论文提出 Energy-Based Reasoners：在潜在推理状态上学习能量函数，把循环推理的更新形式化为能量梯度下降，同一能量同时负责状态精炼、自适应停止与多候选选择，并配合基于状态的探索训练塑造多解能量面。在四个算法推理基准上匹配或超越此前循环推理模型，以更少推理算力取得高准确率与更高多解覆盖率；结论限于结构化算法任务。

### 研究动机

- 循环推理模型通过反复迭代同一个网络块，在潜在空间中逐步精炼答案，用少量参数获得很深的等效计算。这类模型（如 HRM、TRM）在算法推理任务上已能胜过许多大语言模型，但它们缺少对当前推理状态的显式进度度量：更新本身不被任何评估信号引导，何时停止、如何在多个候选中挑选，都要依赖额外的停机头或收敛判据。
- 与之相对，链式思维范式可以把中间步骤暴露成 token 序列，便于评估路径、分配算力和选择答案；潜在空间推理则没有这种显式轨迹。作者提出的核心问题是：能否学一个统一目标，让评估同时引导推理过程、决定停止时机并验证候选答案？
- 能量模型提供了自然的答案：能量值给状态打分，能量梯度给出改进方向。已有能量推理工作要么直接在候选解上定义能量，要么依赖任务规则手工设计能量函数；EBR 的差别是在潜在推理状态上学端到端的能量，并把循环更新本身形式化为能量下降。

### 方法与关键设计

- EBR 的核心改动是把循环推理的更新规则换成能量下降。给定问题 x，模型学习标量能量函数 <span class="paper-math">&#92;(E&#95;&#123;&#92;theta&#125;(z;x)&#92;)</span>，其中 <span class="paper-math">&#92;(z&#92;)</span> 是逐 token 的潜在推理状态，能量越低表示该状态解码出的预测越好。推理时状态按 <span class="paper-math">&#92;(z&#95;&#123;t+1&#125;=z&#95;t-&#92;alpha&#92;nabla&#95;z E&#95;&#123;&#92;theta&#125;(z&#95;t;x)&#92;)</span> 迭代下降，实际实现是投影 Langevin 动力学：每步注入高斯噪声鼓励探索，并把状态投影到单位 RMS 球面上以稳定轨迹。这样同一个能量同时承担三种角色：梯度引导状态精炼、能量值用于在多个独立候选中选最低者、梯度范数作为停止信号。
- 能量网络复用 TRM/EqR 的循环 Transformer 块作为骨干（自注意力加 SwiGLU），只加一个轻量逐 token 能量头把块输出归约为标量，再对全 token 求和；与 TRM 的关键差异在于骨干输出的是能量而非下一状态，状态更新沿负梯度进行，且用单一潜在状态而非层级结构。能量头参数量约占模型百分之几，Maze-Hard 上用 softplus 约束 token 能量非负以避免偏好绕路。
- 训练采用分段深监督：把下降轨迹切成若干段，每段内前段步骤不保留计算图，只对最后若干步回传；由于更新本身依赖能量梯度，反传需要二阶导数。损失由带权重的稳定max交叉熵加收敛损失组成，权重向段末递增。收敛损失把段末状态的平均相对变化残差经 sigmoid 转成收敛分数，用最终预测是否正确做二元交叉熵监督，鼓励正确预测收敛到驻点、阻止错误预测过早静止；该停止准则直接来自动力学，不需要额外可学习的停机头。
- 为避免能量只适配单一下降日程，训练时每段随机采样下降步数和步长，评测用固定配置。针对多解任务，作者提出基于状态的探索建模（SXM）：每个输入维护多条并行下降轨迹，每段只监督与某个有效解最匹配的那条，未选中的轨迹继续演化并保留后续被选资格；前向方向为给定目标选最低损失轨迹，反向方向为给定轨迹从有效解集合中选最匹配目标，并采用不重复分配解的策略防止轨迹坍缩到同一解。
- 与基线的差异可概括为：HRM/TRM 用学习的停机头且更新不受显式评估引导，FPRM 用状态收敛作停止准则但更新无约束，IREM/IRED 等能量方法直接在候选预测上定义能量，而 EBR 在潜在推理状态上定义能量并用梯度下降定义动力学，使驻点与正确解对齐。帮助理解的小例子：图 1 展示一个数独谜题的下降轨迹，错误状态能量较高且步数少，正确解落在能量最低的驻点。

### 与小组方向的关联

## MIRA: Mitigating Pole Geometry Bias in Recurrent Language Models {#arxiv-2611-09412}

**作者：** Róisín Luo, Ihsan Ullah, Christian Gagné, Dong Li, Karyn Morrissey

**命中的作者机构：** Berkeley、UCLA

**作者单位原文：** PASA Lab – University of California, Merced Code : https://roisincrtai.github.io/official-mira-llm/

**论文：** [arXiv](https://arxiv.org/abs/2611.09412) · [本次阅读版本 v1](https://arxiv.org/abs/2611.09412v1)

阅读范围：完整 PDF，共 63 页（含图表、公式及附录），辅以可核对的正文片段

### 原始摘要

We show that the Transformer's recurrent successors --- such as selective state-space models (SSMs), Receptance Weighted Key Value (RWKV), and Retentive Network (RetNet) --- can be characterized as infinite-impulse-response (IIR) systems. The zero--pole geometries of these IIR systems characterize the temporal modes they can represent. However, to trade parallelism, the algebraic structures of the parameterizations of these recurrent systems often give rise to poles constrained to the real axis, thereby inducing an architectural bias in their recurrent dynamics. To unify these recurrent architectures and eliminate their pole geometry bias, inspired by the lattice--ladder realization of general IIR systems, we present \textsc&#123;Mira&#125; (\textbf&#123;M&#125;odal \textbf&#123;I&#125;IR \textbf&#123;R&#125;ecurrent \textbf&#123;A&#125;rchitecture), a unified family of linear-time recurrent architectures for building large language models (LLMs) with a highly parallel algebraic structure. Each \textsc&#123;Mira&#125; block realizes a higher-order IIR system that represents temporal modes from token streams through a lattice--ladder structure, followed by a feed-forward network (FFN). This realization enables the model to represent the temporal modes associated with both real and complex-conjugate poles. We pretrain \textsc&#123;Mira-S&#125;, a 12-layer small-scale LLM with 0.14B parameters composed entirely of \textsc&#123;Mira&#125; blocks. Throughout the pretraining, \textsc&#123;Mira-S&#125; achieves lower perplexity than strong recurrent baselines, exhibits stronger context-window generalization beyond the training length, and attains higher throughput with a dedicated CUDA kernel.

### 一句话速览

论文将 Mamba、RWKV、RetNet 等循环语言模型统一刻画为 IIR 系统，指出其参数化把极点约束在实轴上、无法表示复共轭极点对应的时间模态。作者提出 Mira，用格型-梯型结构实现高阶 IIR 动力学，允许复极点并保持可并行性。预训练 0.14B 的 Mira-S 在困惑度、长上下文泛化和 CUDA 核吞吐上优于强循环基线，结论适用于小规模语言建模场景。

### 研究动机

- Transformer 的因果缩放点积注意力（SDPA）随序列长度呈二次复杂度，长上下文场景下成本高。近年一批线性时间循环架构——选择性状态空间模型（SSM，如 Mamba）、RWKV、RetNet、DeltaNet 等——用固定维度的循环状态替代注意力，成为高效 LLM 的主要候选。这类模型的使用场景与 Transformer 相同：在大规模语料上做下一 token 预测预训练，再用于语言理解与生成。
- 本文的核心问题是：这些循环架构在数学上能否被统一刻画，以及它们的参数化是否引入了系统性的表达能力偏差。作者用数字信号处理中的传递函数视角回答：每个循环系统对应一个输入条件化的 IIR 系统，其零点-极点几何决定了它能表示的时间模态；而为了换取并行性，现有方法的极点几乎都被约束在实轴上，无法表示复共轭极点对应的振荡模态，这是一种架构层面的归纳偏置。
- 与现有工作的差别在于：此前各循环架构被视为彼此独立的设计选择，本文给出统一的传递函数刻画（含形式化验证），并指出实轴极点约束这一共同缺陷；解决方案不是修补某个具体模型，而是借用 IIR 滤波器的格型-梯型规范实现，构造一个天然允许复极点、同时保持高度并行代数结构的统一架构族 Mira。

### 方法与关键设计

- 论文首先把语言序列视为离散时间信号，用 z 变换刻画循环系统的输入输出关系。核心公式是输入条件化的传递函数 <span class="paper-math">&#92;(H(z;x&#95;t)=&#92;frac&#123;A(z;x&#95;t)&#125;&#123;B(z;x&#95;t)&#125;&#92;)</span>，其中分子 <span class="paper-math">&#92;(A&#92;)</span> 是 FIR（有限冲激响应）多项式，分母 <span class="paper-math">&#92;(B&#92;)</span> 是 IIR（无限冲激响应）多项式；分子根称为零点，分母根称为极点。零点决定哪些时间模态被衰减或抵消，极点决定哪些模态被持续或共振地保留。作者在附录中逐一推导了 SDPA、Mamba、RWKV、RetNet、HGRN2、Hyena、DeltaNet 等方法的传递函数，并用数值验证（最大偏差约十的负十二次方量级）和 Lean 4、Z3 形式化验证确认极点范围。
- 关键观察是：为了换取通道级并行性，这些方法的参数化（如 SSM 的对角矩阵）使转移矩阵对称或可对角化，从而所有极点被约束在实轴上。作者构造了一个合成实验：生成四维输入与目标序列，其真实传递函数含非实极点，训练参数匹配的单层 Mira、SDPA、Mamba-S6、RWKV-7 做下一 token 预测；图中可观察到 Mira 的极点分布在复平面内且预测误差显著更低，实轴极点模型无法检索复共轭极点对应的模态。
- Mira 的解法是借用数字信号处理中的格型-梯型（lattice–ladder）实现，这是一般 IIR 系统的规范实现形式。每个 Mira 块先做 RMSNorm 并投影到扩展维度 <span class="paper-math">&#92;(d&#95;e&gt;d&#92;)</span>，然后通过 <span class="paper-math">&#92;(K&#92;)</span> 阶格型级联传播前向信号 <span class="paper-math">&#92;(U&#95;t^&#123;(k)&#125;&#92;)</span>（当前 token 表示）和后向状态 <span class="paper-math">&#92;(V&#95;t^&#123;(k)&#125;&#92;)</span>（携带历史记忆）。核心动力学是双端口散射方程 <span class="paper-math">&#92;(&#92;begin&#123;pmatrix&#125;U&#95;t^&#123;(k-1)&#125;&#92;&#92;V&#95;t^&#123;(k)&#125;&#92;end&#123;pmatrix&#125;=A&#95;t^&#123;(k)&#125;&#92;begin&#123;pmatrix&#125;U&#95;t^&#123;(k)&#125;&#92;&#92;V&#95;&#123;t-1&#125;^&#123;(k-1)&#125;&#92;end&#123;pmatrix&#125;&#92;)</span>，其中 <span class="paper-math">&#92;(A&#95;t^&#123;(k)&#125;=r&#95;t^&#123;(k)&#125;&#92;odot R&#95;t^&#123;(k)&#125;&#92;)</span>，<span class="paper-math">&#92;(R&#95;t^&#123;(k)&#125;&#92;)</span> 是由 Cayley 映射参数化的旋转矩阵，角度由 <span class="paper-math">&#92;(&#92;sin&#92;theta&#95;t=&#92;mathrm&#123;sech&#125;(&#92;alpha&#95;t)&#92;)</span>、<span class="paper-math">&#92;(&#92;cos&#92;theta&#95;t=&#92;tanh(&#92;alpha&#95;t)&#92;)</span> 给出，半径由 Cauchy 映射 <span class="paper-math">&#92;(r&#95;t=&#92;frac&#123;1&#125;&#123;1+&#92;beta&#95;t^2&#125;&#92;)</span> 给出。旋转引入复角度，使离散时间极点 <span class="paper-math">&#92;(r&#95;t e^&#123;i&#92;theta&#95;t&#125;&#92;)</span> 可以离开实轴，同时 <span class="paper-math">&#92;(r&#95;t&#92;in(0,1)&#92;)</span> 保证 Schur 稳定性。
- 控制信号 <span class="paper-math">&#92;(&#92;alpha&#95;t,&#92;beta&#95;t&#92;)</span> 由低秩瓶颈 <span class="paper-math">&#92;(d&#95;r&#92;ll d&#92;)</span> 从输入生成，实现数据依赖的动态调制；输出通过梯型读出聚合各阶段后向状态，配以读出系数、读出方向和选择性门控。初始化方面，作者设计了 Jeffreys 初始化器：把各通道极点对的特征视界设为 Jeffreys 先验的分位数，避免平凡初始化使跨阶段状态转移幅度随 <span class="paper-math">&#92;(K&#92;)</span> 指数衰减、把 IIR 退化成 FIR。
- 并行化依赖一个代数性质：整个级联可写成仿射算子 <span class="paper-math">&#92;(&#92;mathcal&#123;T&#125;&#95;t(&#92;mathbf&#123;V&#125;)=&#92;Phi&#95;t&#92;mathbf&#123;V&#125;+&#92;mathbf&#123;S&#125;&#95;t&#92;)</span>，且时间复合满足结合律，因此任意区间的状态可分解为“前段记忆的传输”加“从零状态出发的段内动力学”。据此把 token 轴切成块，CUDA 核分三阶段：各块从零状态并发汇总出 <span class="paper-math">&#92;((&#92;Phi,&#92;mathbf&#123;S&#125;)&#92;)</span> 对、在块边界做并行扫描恢复入口状态、再并发重放内部状态并产出读出。理论关键路径为 <span class="paper-math">&#92;(2L+T/L&#92;)</span>，取块长 <span class="paper-math">&#92;(L&#92;approx&#92;sqrt&#123;T/2&#125;&#92;)</span> 时达到 <span class="paper-math">&#92;(&#92;mathcal&#123;O&#125;(&#92;sqrt&#123;T&#125;)&#92;)</span>。与基线的差异在于：Mira 用固定阶数的格型级联替代对角/标量衰减，允许复极点，且循环动力学天然编码时序，无需显式位置编码。

## Query-Guided RoPE Modulation for Lost-in-the-Middle Mitigation in Long-Context LLMs {#arxiv-2611-09554}

**作者：** Peiyu Zhang, Heng Ping, Shinibali Bhattacharyya, Anwesan Pal, Nikos Kanakaris, Kevin Cheang, Shixuan Li, Wei Yang, Paul Bogdan

**命中的作者机构：** Amazon

**作者单位原文：** Amazon Web Services

**论文：** [arXiv](https://arxiv.org/abs/2611.09554) · [本次阅读版本 v1](https://arxiv.org/abs/2611.09554v1)

阅读范围：完整 PDF，共 13 页（含图表、公式及附录），辅以可核对的正文片段

### 原始摘要

Long-context language models often neglect information in the middle of the input, a phenomenon known as "lost-in-the-middle". Part of this gap may stem from the long-range decay of rotary position embedding (RoPE), which weakens the positional signal between distant tokens. Existing input compression deletes low-importance tokens, and attention reweighting acts only after RoPE has weakened this signal. RoPE-level methods modify positions directly but apply the same remapping to every query. To address these limitations, we propose QGPM (Query-Guided Positional Modulation), a training-free method that reshapes RoPE positions using query relevance from the model's own attention heads. QGPM builds a broad relevance map for lower layers and a sharp one for upper layers. Low-relevance tokens advance by less than one position on fast-rotating planes, pulling relevant evidence toward the query. Slow-rotating planes keep the original layout, with every token in place. Experiments on NoLiMa and RULER with multiple context lengths show that QGPM improves over base models and strong baselines, with the largest gains on retrieval tasks, and generalizes across multiple backbones. Our code is available at this https URL .

### 一句话速览

针对长上下文模型“lost-in-the-middle”问题，提出训练自由的 QGPM：从模型自身检索头读取查询相关性，在快旋转频率平面上压缩低相关 token 的位置步长，把相关证据拉近查询，慢平面保留文档布局，低层用宽图、高层用锐图。在 NoLiMa 和 RULER 上四个骨干均优于基线，检索任务收益最大，QA 任务与骨干持平。

### 研究动机

- 长上下文语言模型虽然支持数十万 token 的窗口，但常只关注输入首尾而忽略中部，即“lost-in-the-middle”现象；在证据与查询词汇重叠很少的检索场景中，准确率随上下文变长急剧下降。这类任务的输入是长文档加问题，输出是答案，典型场景包括长文档问答和检索增强生成。论文的目标不是继续扩大窗口，而是让模型更好地利用已在窗口内的信息。
- 作者把部分原因归于旋转位置编码（RoPE）的长程衰减：RoPE 把位置表示为多个不同频率二维平面上的旋转，快旋转平面在长距离上转满多圈后不再携带一致的距离信号，远处证据只能通过更少的平面与查询匹配。由于衰减取决于位置距离，把相关证据的位置拉近查询可以在不改文本的情况下缓解衰减。
- 已有路线各有缺陷：输入压缩（如 LLMLingua-2）删除低重要性 token，丢失分级相关性信息；注意力重加权（如 PASTA）只能在 RoPE 已削弱位置信号之后放大注意力；RoPE 层面的改写（如 Ms-PoE、Self-Extend、STRING）不依赖查询，对证据和干扰一视同仁。已有工作虽发现少数注意力头能定位查询相关片段，但只用该信号做 KV 选择、token 过滤或文档重排。论文要回答的问题是：能否用模型自身的查询相关性直接重塑 RoPE 位置，同时保留每个 token。

### 方法与关键设计

- QGPM 的输入是长上下文提示（系统提示、任务指令、上下文、问题），输出仍是模型答案，方法本身不改变输入文本和模型权重，只在推理时改写 RoPE 位置表。动机来自 RoPE 的频率结构：每个二维平面以角频率 <span class="paper-math">&#92;(&#92;omega&#95;m=&#92;theta^&#123;-2m/d&#125;&#92;)</span> 旋转，注意力 logit 只通过位置差 <span class="paper-math">&#92;(&#92;Delta p&#92;)</span> 依赖位置，每个平面贡献一个振荡项。当 <span class="paper-math">&#92;(&#92;Delta p&#92;)</span> 超过平面波长 <span class="paper-math">&#92;(&#92;lambda&#95;m=2&#92;pi/&#92;omega&#95;m&#92;)</span> 时，该平面在公式 <span class="paper-math">&#92;(&#92;mathrm&#123;logit&#125;(i,j)=&#92;sum&#95;m[a&#95;m&#92;cos(&#92;omega&#95;m&#92;Delta p)+b&#95;m&#92;sin(&#92;omega&#95;m&#92;Delta p)]&#92;)</span> 中的项随距离不再一致变化而趋于抵消，远处证据只能通过更少平面匹配，作者称之为 RoPE 的长程衰减。
- 方法分两次前向。第一次是普通 prefill，只跑到最深选定注意力头所在层，从少量“检索头”读取查询行（问题 token 加提示末尾若干 token）到每个上下文 token 的最大 RoPE logit 作为相关性信号，按句取最强 token 得到句子分数，各头在句间标准化后平均。头集合每个骨干只校准一次：在 NoLiMa 的留出样本上按证据句的平均倒数排名挑选，校准不更新任何权重。
- 随后把句子排名塑造成两张相关性图：宽图用较大的 K 和较软的温度 T，让多个候选句保持相关；锐图用较小的 K 和较硬的 T，只保留最相关句。分数经 <span class="paper-math">&#92;(f&#95;i=&#92;sigma((K-0.5-&#92;rho(i))/T)&#92;)</span> 映射，最高句为 1，最低句为 <span class="paper-math">&#92;(s&#95;&#123;&#92;mathrm&#123;low&#125;&#125;&#92;)</span>。每张图中第一个相关句之前的上下文构成“受保护前缀”，分数恒为 1——由于因果注意力下证据的表示由其前文构建，保护前缀可保持证据编码完整，压缩只作用于证据与查询之间的区段。
- 核心的频率感知步长设计：以锚定长度 <span class="paper-math">&#92;(L&#95;a&#92;)</span> 定出边界平面 <span class="paper-math">&#92;(m^&#42;=m(L&#95;a)&#92;)</span>，用 sigmoid 门 <span class="paper-math">&#92;(g&#95;m=&#92;sigma((m-m^&#42;)/&#92;tau&#95;m)&#92;)</span> 区分快慢平面，步长为 <span class="paper-math">&#92;(&#92;delta&#95;m(j)=&#92;max(s(j)+(1-s(j))g&#95;m,&#92; &#92;epsilon)&#92;)</span>。慢平面上 <span class="paper-math">&#92;(g&#95;m&#92;approx1&#92;)</span>，所有 token 保持单位步长，文档粗布局不变；快平面上低相关 token 的步长降到约 <span class="paper-math">&#92;(&#92;max(s(j),&#92;epsilon)&#92;)</span>，约 <span class="paper-math">&#92;(1/&#92;epsilon&#92;)</span> 个连续低相关 token 共享一个位置，局部词序被模糊但不删除。位置由步长累加 <span class="paper-math">&#92;(p'&#95;&#123;m,j&#125;=&#92;sum&#95;&#123;k&#92;le j&#125;&#92;delta&#95;m(k)&#92;)</span> 得到，严格递增；压缩段之后的所有 token 在快平面上整体前移，从而把相关句拉近查询。作者假设这种模糊能弱化干扰文本，属于待验证的机制解释。
- 层间调度上，低于 <span class="paper-math">&#92;(&#92;ell&#95;s=&#92;lfloor n&#95;&#123;&#92;mathrm&#123;layer&#125;&#125;/2&#92;rfloor&#92;)</span> 的层用宽图，其余层用锐图，各层 KV 缓存按对应图坐标存储。作者假设分工：低层从局部上下文构建表示，被模糊的文本无法在后续恢复，故宽图保留更多候选句；选定头集中在中上层，锐图在那里减少竞争句。解码从每张图最后一个 prompt 位置起以单位步长继续。与基线的差别在于：压缩方法删 token、注意力重加权在 RoPE 已衰减信号之后介入、既有 RoPE 改写与查询无关，而 QGPM 用模型自身注意力信号做查询感知的位置改写且不删任何 token。额外开销为一次止于最深选定层的 prefill，解码每步成本与标准 RoPE 相同。

### 实验设计与论证方式

- 实验围绕三个研究问题组织：是否优于现有推理时方法、位置调制是否优于按相关性选择或重排内容、注意力头读出的相关性接近人工标注的程度。模型为四个指令微调骨干（Qwen2.5-7B、Qwen3-4B、Ministral-8B、Granite-3.3-8B），RoPE 基数从 5×10^6 到 10^8；除 Ministral-8B 的 64K 超出配置窗口外，所有输入都在原生窗口内。基准为 NoLiMa（4K–32K）和 RULER 的 QA-1、QA-2、NIAH-MK、NIAH-MV（4K–64K），指标为答案包含金标的准确率，每个 RULER 任务每个长度 500 样本。

## Cross-Layer TopK: Dynamically Allocating Sparsity Across Layers in Transcoders {#arxiv-2611-09233}

**作者：** Anyuan Zhuo, Shaohua Zhang, Tianle Li, Yuan Lin, Diandian Gu, Jun Wang, Pinyan Lu

**命中的作者机构：** ByteDance

**作者单位原文：** ByteDance Seed, 2Shanghai University of Finance and Economics

**论文：** [arXiv](https://arxiv.org/abs/2611.09233) · [本次阅读版本 v1](https://arxiv.org/abs/2611.09233v1)

### 原始摘要

Cross-Layer Transcoders (CLTs) decompose the activations of large language models into human-interpretable features and trace how these features interact across layers to form circuits, making them a key tool for mechanistic interpretability. However, training CLTs effectively and efficiently is hard. Beyond the usual trade-off between sparsity and reconstruction quality, a CLT has to model all layers at once, which adds a further challenge. The common JumpReLU recipe controls sparsity only indirectly through a penalty, while the direct extension of TopK selects a fixed number of latents in every layer. Yet reconstruction difficulty differs widely across layers, and intermediate layers are much harder than others, so giving every layer the same budget is suboptimal. We propose Cross-Layer TopK, which sets a single L0 budget for the whole model and dynamically allocates it across layers during training. In a comparison with JumpReLU and other TopK variants on Qwen3-8B-Base, this gives lower FVU while using 20% fewer active latents than JumpReLU. The better reconstruction carries over to circuit tracing, yielding more complete circuits with higher replacement and completeness scores. The fixed per-token budget of Cross-Layer TopK also makes it easy to pair with sparse decoding, which cuts both computation and communication and gives a 2.9x speedup per training step. We further show that Cross-Layer TopK follows scaling laws in both latent size and sparsity. We have open-sourced the weights of our CLT at this https URL .

### 一句话速览

论文研究跨层转码器（CLT）的稀疏激活机制，提出 Cross-Layer TopK：对整个模型设一个统一的 L0 预算，训练时把激活名额动态分配到各层。在 Qwen3-8B-Base 上取得比 JumpReLU 和逐层 TopK 更低的重构误差，电路追踪更完整，并借助固定稀疏度实现稀疏解码，训练步加速约 2.9 倍。

### 研究动机

- 机制可解释性希望把大语言模型的计算解释成人类可读的特征及其相互作用，即所谓电路。常用工具是稀疏字典学习：编码器把激活映射到一组稀疏、过完备的特征，解码器再从特征重构目标。稀疏自编码器（SAE）重构本层激活，转码器（Transcoder）从 MLP 输入重构其输出，跨层转码器（CLT）则允许第 l 层残差流中读出的特征写入所有后续层 l'≥l 的 MLP 输出，从而把分布在多层计算中的机制用一个特征捕捉。
- 训练 CLT 的难点在于同时优化重构与稀疏，且所有层必须联合建模。现有 CLT 主流配方用 JumpReLU，通过惩罚项间接控制稀疏度，最终稀疏度无法从惩罚系数预知，需要反复搜索；直接把 TopK 扩展到 CLT（逐层固定 k 个激活）则牺牲了跨层自由度——各层重构难度差异很大，中间层最难，均匀分配预算并不最优。
- 本文要回答的问题是：能否设计一种稀疏机制，既像 TopK 一样精确控制总稀疏度，又像 JumpReLU 一样允许模型在训练中自行决定各层的稀疏分配。

### 方法与关键设计

- 先看 CLT 的形式化定义。设模型有 L 层，第 l 层 MLP 输入为 <span class="paper-math">&#92;(x&#95;l&#92;)</span>、输出为 <span class="paper-math">&#92;(y&#95;l&#92;)</span>，残差流维度为 n。每层编码器把 <span class="paper-math">&#92;(x&#95;l&#92;)</span> 映射为预激活 <span class="paper-math">&#92;(z&#95;l = W^&#123;enc&#125;&#95;l x&#95;l &#92;in &#92;mathbb&#123;R&#125;^m&#92;)</span>，m 为潜变量维度且远大于 n。所有层的激活 <span class="paper-math">&#92;(A = &#92;sigma(Z)&#92;)</span> 由稀疏激活函数 <span class="paper-math">&#92;(&#92;sigma&#92;)</span> 产生，解码器按 <span class="paper-math">&#92;(&#92;hat&#123;y&#125;&#95;l = &#92;sum&#95;&#123;l' &#92;le l&#125; W^&#123;dec&#125;&#95;&#123;l'&#92;to l&#125; a&#95;&#123;l'&#125;&#92;)</span> 重构第 l 层的 MLP 输出，即每个激活特征通过跨层解码权重写入所有后续层。
- 核心机制是 Cross-Layer TopK：把一个 token 在所有 L 层的潜变量汇合，按标量分数选出全局最大的 K 个激活，其余置零。分数沿用常见做法，取整流后的预激活乘以该特征解码权重的范数：<span class="paper-math">&#92;(s^l&#95;i = &#92;max(z^l&#95;i, 0) &#92;cdot &#92;| [w^l&#95;&#123;i&#92;to l&#125;; w^l&#95;&#123;i&#92;to l+1&#125;; &#92;ldots; w^l&#95;&#123;i&#92;to L&#125;] &#92;|&#95;2&#92;)</span>，即该特征将写入后续各层的总输出的 ℓ2 范数，衡量其潜在影响。被选中的位置保留整流后的值 <span class="paper-math">&#92;(&#92;max(z^l&#95;i, 0)&#92;)</span>。这样每个 token 的激活总数固定为 K = L·k，与逐层 TopK 总预算相同，但各层分配由模型自学。
- 训练目标是对所有层求和的重构损失 <span class="paper-math">&#92;(&#92;mathcal&#123;L&#125;&#95;&#123;recon&#125; = &#92;sum&#95;&#123;l=1&#125;^&#123;L&#125; &#92;|y&#95;l - &#92;hat&#123;y&#125;&#95;l&#92;|&#95;2^2&#92;)</span>，各层 MLP 输入输出预先归一化到期望范数 <span class="paper-math">&#92;(&#92;sqrt&#123;n&#125;&#92;)</span>，使各层误差可比。为防止死潜变量，加入 Gao 等的辅助损失并适配到跨层选择：对最近 w 步未激活的死潜变量，用同样的全局 TopK 选出一批，让它们重构活潜变量留下的误差，总损失为 <span class="paper-math">&#92;(&#92;mathcal&#123;L&#125; = &#92;mathcal&#123;L&#125;&#95;&#123;recon&#125; + &#92;alpha &#92;mathcal&#123;L&#125;&#95;&#123;aux&#125;&#92;)</span>。
- 训练过程：在 Qwen3-8B-Base 上收集激活，语料混合预训练文本、推理链与指令数据，激活存入缓冲区随机抽取微批次，使每批混合多序列 token；范数异常的 token 被过滤。所有模型用 AdamW 训练相同 token 数，超参一致；预算 K 从较大值线性衰减到目标值后保持恒定，辅助损失系数固定。
- 与基线的差异：JumpReLU 用惩罚项间接控制稀疏，惩罚随接近目标而衰减导致稀疏停滞在目标之上；Per-Layer TopK 每层固定 k 个，无法跨层再分配；Cross-Layer BatchTopK 在训练批次上分配预算，但推断时需要事后校准每特征阈值，训练与推断不匹配。Cross-Layer TopK 的选择只依赖单个 token，无需事后阈值。
- 推断与训练一致：每 token 恰好 K 个激活，稀疏模式在解码前已知且形状固定，因此可直接配稀疏解码——编码器沿潜变量轴分片、解码器沿模型维度分片，只跨张量并行秩交换 K 个激活潜变量，避免稠密重构 all-reduce。论文还给出三种数值等价的稀疏解码核（dense、gather、embedding_bag），其中 embedding_bag 把 gather、缩放和按 token 求和融合成一个核。

### 实验设计与论证方式

- 实验设置：在 Qwen3-8B-Base（36 层）上训练 CLT，激活来自 Olmo 3 语料，按预训练文本、推理链、指令数据约 5:2:1 混合；激活存入缓冲区随机抽取微批次，有效批大小 32768 token，所有模型训练相同 token 数（3.2B）并使用一致的超参数。重构质量用 FVU（未解释方差比例），在留出验证集上测量。
- 比较对象为四种架构，潜变量维度均为 32768：JumpReLU（目标 L0 为 360，实际平均 452）、Per-Layer TopK（每层 10 个，共 360）、Cross-Layer BatchTopK（训练时批次选择，推断时用事后阈值）、Cross-Layer TopK（每 token 360）。分析部分考察各层预算分配与 FVU 的关系；电路评估用 100 条筛选过的验证提示，计算 replacement 和 completeness 分数（衡量归因图中影响经由特征而非误差节点传播的比例，越高越好）；效率实验在 128 GPU 上比较三种稀疏解码核与基线的步时。
- scaling 分析分别固定每层预算扫潜变量维度、固定维度扫预算，每个点是独立训练的模型，在 log-log 空间拟合幂律。这是纯离线研究，论文未报告线上或 AB 实验。

### 结果与证据

- 在验证集上，Cross-Layer TopK 取得四种架构中最低的整体 FVU，且在相同总预算下优于逐层 TopK；JumpReLU 虽然用了更宽松的预算，FVU 却最差，且其死潜变量比例远高于三种 TopK 架构，说明其稀疏预算集中在字典的很小一部分。Cross-Layer BatchTopK 训练时批次选择下 FVU 略低于本文方法，但推断时用事后阈值后明显变差，体现训练-推断不匹配。这些结果支持跨层动态分配的价值，但均为单一模型上的离线重构指标。（Table 1）

  图表观察（PDF 第 6 页）：Table 1（m=32768，验证集）：JumpReLU L0=452, FVU=32.17%, dead latents=41.2%；Cross-Layer BatchTopK（threshold, inference）L0=289, FVU=29.04%；Per-Layer TopK L0=360, FVU=27.64%, dead=3.0%；Cross-Layer TopK L0=360, FVU=27.07%, dead=3.2%；Cross-Layer BatchTopK（batch selection, training）L0=360, FVU=26.98%, dead=3.0%。

- 在相同 100 条提示上，Cross-Layer TopK 的 replacement 与 completeness 分数均为四种架构最高。相同预算下它超过逐层 TopK，说明更好的重构带来更完整的电路；JumpReLU 的 replacement 分数排第二，作者解释为其预算更大、给了归因图更多特征路径，而本文方法用更少激活仍超过它，说明增益来自重构质量而非预算。该结果只覆盖筛选过的提示分布，不能直接推广到任意提示。（Table 2）

  图表观察（PDF 第 8 页）：Table 2（100 条提示平均）：JumpReLU L0=452, Replacement=0.589, Completeness=0.897；Per-Layer TopK L0=360, Replacement=0.577, Completeness=0.894；Cross-Layer BatchTopK L0=289, Replacement=0.578, Completeness=0.889；Cross-Layer TopK L0=360, Replacement=0.617, Completeness=0.902。

- 在 128 GPU、固定批大小与每层预算的配置下，三种稀疏解码核都显著降低训练步时，其中融合核最快，计算与通信时间均大幅下降，相对基线获得约 2.9 倍的每步加速。该加速是训练步的端到端计时，且依赖固定每 token 激活数这一机制特性；其他并行配置下的收益未报告。（Table 3）

  图表观察（PDF 第 9 页）：Table 3（128 GPUs, k=10, B=8192）：Baseline（latent-sharded）step 1.025s（compute 0.800s, comm 0.224s, 1.0×）；sparse decode, dense 0.552s（1.9×）；gather 0.436s（2.4×）；embedding_bag 0.355s（compute 0.281s, comm 0.074s, 2.9×）。

- 固定每层预算扫潜变量维度、固定维度扫每层预算，整体 FVU 均呈幂律下降，两个拟合指数与 TopK SAE 的已发表 scaling 律同量级。由于 Cross-Layer TopK 精确固定总稀疏度，两个轴可以独立扫动，这是 JumpReLU 做不到的；但拟合基于有限个训练点，指数外推到更大规模需谨慎。（Figure 4）

  图表观察（PDF 第 10 页）：Figure 4：左图固定 k=10，m 从 2^13 到 2^15，FVU 从 33.77% 降至 27.07%，拟合 FVU∝m^-0.16；右图固定 m=2^15，k 从 5 到 20，FVU 从 29.62% 降至 24.65%，拟合 FVU∝k^-0.13。

### 与小组方向的关联

论文属于模型结构/稀疏机制设计，命中小组对模型架构设计与 Attention 之外稀疏机制的兴趣；其跨层动态分配预算的思想与推荐中动态分配容量的思路有类比空间，但应用场景是机制可解释性而非推荐/检索，未验证下游收益，评分据此保守。

### 局限与阅读边界

- 作者已承认的局限：CLT 的解码器随层数平方增长，每次大规模训练消耗大量算力，这使作者无法扩展到更大规模；论文只在一个模型（Qwen3-8B-Base）和一种语料混合上验证，跨模型与跨语料的普适性未检验。
- 从材料可合理提出的验证问题：Cross-Layer TopK 的优势依赖中间层更难重构这一观察，若目标模型层间难度分布不同，动态分配的收益是否保持需要验证；电路评估仅 100 条提示且经过严格筛选（预测正确、低频、非重复），分数对提示分布的敏感性未讨论；2.9 倍加速是在特定张量并行配置与批大小下测得的，其他配置下的收益未报告。
- 本次阅读范围不足之处：论文声明开源了 CLT 权重，但本次未核验该仓库内容与训练代码是否完整公开，复现环境未核验；scaling 指数只在与 TopK SAE 的可比范围对照，未与其他 CLT 训练配方系统比较。
